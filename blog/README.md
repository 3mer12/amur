# مدونة عامر_

موقع ثابت بدون أي اعتماديات. الشكل بهويتك (ليل / لُبان / بُن، وكروما للتمييز فقط)، ويدعم الوضع الداكن والفاتح تلقائيًا.

## الملفات

| الملف | وظيفته |
|---|---|
| `site.json` | اسم المدونة، الوصف، حسابك، ورابط الموقع |
| `content/posts/` | المقالات (ملف Markdown لكل مقال) |
| `content/about.md` | صفحة «من أنا» |
| `public/style.css` | كل التصميم |
| `public/images/` | الصور التي ترفعها من لوحة النشر |
| `build.mjs` | يبني الموقع إلى مجلد `dist` |
| `.pages.yml` | إعداد لوحة النشر (Pages CMS) |

## تجربتها على جهازك

يلزم Node.js فقط:

```
node build.mjs
npx serve dist
```

## نشرها مجانًا

1. أنشئ مستودعًا على GitHub وارفع هذا المجلد.
2. في Cloudflare: Workers & Pages ثم Create ثم Pages ثم Connect to Git، واختر المستودع.
3. إعدادات البناء:
   - Build command: `node build.mjs`
   - Build output directory: `dist`
4. بعد دقيقة تحصل على رابط مثل `اسم.pages.dev`. ضعه في `site.json` عند الحقل `url`.

## لوحة النشر

1. افتح pagescms.org وسجّل الدخول بحساب GitHub.
2. اختر مستودع المدونة.
3. من «المقالات» أضف مقالًا جديدًا، واكتب، واضغط حفظ.
4. يُنشر المقال تلقائيًا خلال دقيقة تقريبًا. وخيار «مسودة» يخفيه عن الموقع.

## نشر مقال بدون اللوحة

أنشئ ملفًا في `content/posts/` باسم مثل `2026-12-01-عنوان.md`:

```
---
title: عنوان المقال
description: وصف قصير
date: 2026-12-01
tags: تصميم، مونتاج
---

نص المقال هنا.
```

## نطاق خاص (اختياري)

من Cloudflare Pages ثم Custom domains. شراء النطاق هو الشيء الوحيد المدفوع.
